# goBILDA's example code

`BioBuzzStarterbotTeleopMecanum.java` is goBILDA's official TeleOp for the StarterBot with mecanum wheels (2026–27), from the [StarterBot resource guide](https://www.gobilda.com/ftc-starterbot-base-with-mecanum-wheels-resource-guide-2026-2027/). It's MIT licensed (see the header in the file) and unchanged except for its package.

We keep it as a known-good reference. If our **Main TeleOp** misbehaves, run **Mec BioBuzz StarterBot Teleop** to check whether the problem is the robot or our code. Make our changes in `robot/StarterBot.java` and `opmodes/`, not here.
